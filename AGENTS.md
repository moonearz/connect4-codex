# Agent Instructions

## Project
Connect Four simulator, web application, and AI research.

## Development
- Use Python 3.13.
- Follow the existing project structure.
- Use pytest for testing.
- Use Ruff for linting.
- Keep the game engine independent of Flask.
- Prefer simple, readable implementations.

## Testing
- Run tests after modifying game logic.
- Add tests for new functionality.
- Do not consider a feature complete if tests fail.

## AI Research
- Benchmark agents against established baselines.
- Alternate starting players during evaluation.
- Record experimental results.
- Make experiments reproducible using random seeds.

## Restrictions
- Do not deploy to production.
- Do not modify unrelated repositories.
- Do not use paid external services without approval.
